### N01 High: key screens opened from Settings accept no input
- Screens: r2-24 (Anthropic API key), r2-25 and r2-26 (OpenRouter, after Enter: `Nothing was typed. Paste the key, or press Esc to go back.`), r2-29 (Tavily). Size 120x36. Repro: Settings > API Key, type `sk-or-v1-fake`, or send it one character at a time, or add Enter in the same write: nothing is echoed and Enter reports an empty field. The same screen reached through Start with no key works (r2-06/07).
- This turns F03 from "invisible" into "nothing is received": a user cannot set or change a key from Settings at all.
- Fix: find why the Settings path does not read input (likely the input mode set by the previous menu); share one reader with the Start gate and test both entry paths.

### N02 Med: long key paste is saved and then declared rejected
- Screens: r2-08, r2-09. A 360-character paste echoed 97 stars with no count, then `Saved. OpenRouter rejected this key: User not found.` The key is stored (`Current sk-or-...-v1-`) although the live check failed, and the menu goes on to start with it; the first task then fails with a 401 box (r2-18).
- Fix: cap the accepted length (about 200), show `*** (360)`, and do not save a key the check rejected (or ask `Save anyway?`).

### N03 Med: palette does not fit small windows
- r2-43-80x24: 17 rows of palette plus rules fill rows 2-22 of 24; r2-43-60x20: entries stop at `/checkpoints`, `/quit` and `/exit` are not visible and there is no scroll marker. Descriptions are clipped mid-word (same as F11).
- Fix: show at most (rows - 6) entries with a `+3 more` line, filter as you type, and truncate with `…`.

### N04 Med: filler text in the answer box
- r2-41b: the second task prints `· I added "bye" to notes2.txt, which now contains "hi" and "bye".` and then a box saying `The task is complete. I successfully appended "bye" ... and the final answer has been provided. There is no next action required.` The first task's box is fine (r2-40). The box repeats the narration and talks about itself.
- Fix: show only the final answer in the box; drop the narration line when the box exists; suppress meta sentences such as "the final answer has been provided".

### N05 Med: resize leaves old output at its old width
- r2-42-80x24: the box lines print `┌────...` to the edge with no `┐`, text cut at `and the f`, and the clock row is cut at `Anthropi`. The status line and rules re-lay out, but the transcript does not.
- Fix: repaint the visible transcript at the new width on resize, or cap boxes to the current width at draw time and redraw them.

### N06 Low: API Key does nothing on the subscription route
- r2-33: with `Provider Anthropic (Claude subscription)` the `API Key` row accepts Enter and nothing happens. Fix: open a short screen or show a line: `Not used with the Claude subscription. Switch the route under AI Provider to set a key.`

### N07 Low: placeholder after a failed run
- r2-18: after a 401 error (`+0 lines, -0 lines`) the prompt says `Review the changed files`. Fix: only suggest a review when files changed, otherwise `Try again, or ask something else`.

### N08 Low: Ctrl-C hint behaviour
- r2-13: the hint appears in the prompt, which is good, but the first Ctrl-C on an empty box does nothing visible, and the page shifts up one row (logo row 0 moves to row 0 from row 1). The hint mentions `quit`/`exit` but `/quit` is the palette entry. Fix: show the hint on the first press, say `Ctrl-C again, or /quit, to close`, and do not shift the header.

### N09 Low: accidental Exit
- During this review TMT was closed twice by `Up`, `Enter` in the menu or Settings (Up on the first row wraps to `Exit`, and `Exit` closes at once, also `Close TMT and end the session` when a session is live). Fix: no wrap, or a `Quit TMT?` confirm like Esc has.

## 3. What works well
- Esc on the main menu now asks `Quit TMT?  Enter Quit  Esc Stay` (r2-03); the footer states `Esc Quit`.
- Start without a key goes to the key screen, echoes `*` while typing, gives a clear `That is too short for an OpenRouter key` message and Esc returns to the menu (r2-04 to r2-07). The legacy double flow is gone.
- Provider and route wording is now consistent: `Anthropic (Claude subscription)`, `Using your Claude subscription - API key not used`, `(active)` only where true (r2-22, r2-32).
- The slash palette now includes `/help`, `/quit`, `/exit`; `/he` filters to `/help`; `/help` prints commands and the key line (`Enter sends the line, Esc clears it, Tab completes a command, Up recalls...`) (r2-14, r2-15).
- Live run on haiku via the subscription: `Created file: notes2.txt  +1 -0`, an indented answer box, a clear `Working. Type to queue the next task. Ctrl-C to stop.` prompt and `1 queued task - Up to edit, and they run when this one finishes`; the queue ran and appended `bye` correctly (r2-37 to r2-41).
- API error is shown as a boxed, indented one-liner: `OpenRouter error - OpenRouter HTTP 401: User not found.` (r2-18). Up recall shows `From history - Enter sends it as a new task` (r2-19). Multi-line paste folds to `[Pasted text #1 +3 lines]` (r2-17).
- Width cap on wide terminals (r2-47, r2-48) and a proper bottom-anchored prompt after the palette closes (r2-44). The status line condenses at 80 columns (`+2 -0  ~12k ctx  7k out`).
- Reply Format toggles TAGS/JSON cleanly and back (r2-30). Danger Zone keeps the default cursor on Back (r2-31).

## 4. Improvement ideas
1. Fix N01 first: one shared secret-input reader for the Start gate and all Settings key screens, with a test that types a key in each entry path.
2. Make the final answer one block: `Done`, the answer, then a compact list of tool rows and elapsed time; no narration line when a box follows.
3. A resize hook that repaints the transcript, a `+N more` palette with filtering, and `…` truncation in Settings so 60x20 stays usable.
4. Move the THINKING indicator into the status line (`Thinking 12s`), ASCII only, indented by 2.
5. Repaint the transcript (or say it is kept but hidden) on Resume.
6. Add a confirmation line when Reply Format changes, with two lines of help on TAGS vs JSON; update Help to cover all providers and the Claude subscription route.
7. Do not store a key that the live check rejected; show the length instead of a long run of stars.
8. Lift the remaining dim greys (narration, tip, `+1 -0`, clock) to the same level as the footers.
9. Add the pyte driver as an automated test: the same screens at 4 sizes with assertions for no line wider than the window, no mid-word clip, and echo present after the first typed key on every key screen.
