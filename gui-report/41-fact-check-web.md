## What this changes for the decision
1. Wire format: keep the literal `"jsonrpc":"2.0"` field. Codex omits it; copying that would break StreamJsonRpc and ACP clients (this also matches the locally tested engine stub in 30-native-dotnet-packaging.md, which sends it).
2. ACP's official Python SDK needs Python 3.10+, so for a 3.8+ codebase a stdlib adapter is the right call (the report already proposes that).
3. Everything else the report leans on for the "Electron is the industry default, Tauri has one real precedent (gptme)" argument checks out: Goose and Claude Desktop are Electron, Jan and gptme are Tauri, and the AnythingLLM CVE is real and exactly on point for rendering model markdown in a Node-enabled shell.
