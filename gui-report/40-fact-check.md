## Net effect on the user's decision

- Nothing checked overturns the recommendations. Two statements should be softened: the PySide6 popularity range (use ~2.7M/month) and the WPF Fluent "experimental" wording (only the in-code `ThemeMode` API is experimental).
- Items that are legitimately decision-relevant and now confirmed: Flet 1.0's single-threaded loop (bad fit for TMT's threaded engine), PyQt6 being GPL-only, NZ individuals being excluded from Artifact Signing (a company or SignPath/other route is needed), EV certs giving no SmartScreen shortcut, and Python >=3.10 floors on PySide6 / Flet / NiceGUI / the ACP SDK (TMT claims 3.8+, so every GUI path means shipping its own interpreter inside the frozen app).
- Still unverified by me: the Build 2026 WinUI statements, Premium-tier Artifact Signing price, Velopack's delta/per-user/signing flags, WinUI Phase 3 date from a Microsoft primary source.
